Expand description

Per layer, (local delta count, remote delta count) under rows, for circuit’s channels prepared against hash.

Layers are reported in application order: circuit order for adjoint == false, reverse order for adjoint == true, matching Direction::Heisenberg.

A diagnostic answering “how much of this circuit crosses a partition boundary?” without running a layer. The counts do not depend on rank, so it reports from partition 0.

§Panics

Panics if any channel declines Channel::prepare, the same condition on which propagate panics.
