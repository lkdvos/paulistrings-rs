Expand description

What one layer did, seen across the whole group.

The per-partition vectors are indexed by rank and are all P long.

Fields§

§bits: u8

Bucket bits every partition held for this layer — one number, because the count is agreed collectively before the layer runs.

§remote_deltas: u32

Remote deltas the layer had. Also one number: a delta is remote by its mask alone, so every partition reaches the same verdict. Zero means the layer was purely local and made no transport call.

§collectives: u32

Collective calls the layer issued, not counting the exchange itself (remote_deltas reports that): the bucket-count all-reduce, when the schedule called for one, plus whatever the policy’s collective finalization ran. One number like the two above — the schedule is a function of the layer index and the plan, both rank-independent, so every partition issues the same calls.

§circuit_index: u32

This layer’s position in Circuit::channels, independent of propagation direction. One number: every partition runs the same channel in lock-step.

§application_index: u32

This layer’s position in the propagation loop (k). One number, for the same reason as circuit_index.

§gate_name: &'static str

Channel::debug_name of the applied channel. One value, for the same reason as circuit_index.

§terms_in: Vec<usize>

Terms each partition held before the layer.

§terms_out: Vec<usize>

Terms each partition held after the layer, i.e. after keep_term and the collective finalization.

§rows_sent: Vec<Vec<u64>>

Rows sent, rows_sent[from][to]. The diagonal is always zero — a partition never sends to itself.

§bytes_sent: Vec<Vec<u64>>

Wire bytes sent, bytes_sent[from][to], for the same rows.

§rows_received: Vec<u64>

Rows each partition received, summed over its partners.

§nanos: Vec<u64>

Each partition’s own elapsed wall time for the complete gate, indexed by rank. Ranks are not synchronized mid-layer, so max is a critical-rank proxy rather than a globally elapsed time, and the spread between min/median/max is the group’s timing skew.
