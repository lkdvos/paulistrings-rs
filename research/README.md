# Research

Free-form space for ideas, plans, notes, and literature.
Nothing here is load-bearing for the build — it is a thinking surface.

- `ideas/`        — half-formed proposals, "what if we…" notes. One file per idea.
- `plans/`        — concrete plans we intend to execute. Dated.
- `notes/`        — running notebooks: experiments, profiling sessions, dead ends.
- `literature/`   — paper summaries, links, BibTeX, PDFs (gitignored if large).

Naming convention: `YYYY-MM-DD-short-slug.md`.
Keep the date so the timeline of thinking is preserved even after files move around.
