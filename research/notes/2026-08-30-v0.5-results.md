# v0.5 engine optimizations: measured results

Host: ccqlin038 (2× Xeon Gold 6244, 16c/32t, 2 NUMA nodes, `powersave`,
shared box). rustc 1.94.0. Baseline for every comparison:
`benchmarks/results/2026-08-30-ccqlin038/v04-clean-baseline.{json,txt}` +
`-probe.json` (v0.4 framework note). Per-slice campaigns in the same
directory: `v05-trackR`, `v05-S1` (regressed, superseded), `v05-S1b`,
`v05-S2` — each with criterion JSON, probe JSON, and an HTML report.
Plan: `~/.claude/plans` v0.5 plan; commits `6a18fa1`, `5ed788d`, `a7cc8e9d`,
`6f3493e`, `16ba505`.

## Policy change first (drives Track S)

User directive: floating-point associativity variation in results is
acceptable. Bitwise bucket-count independence is **dropped** as a
requirement; the v0.3 delta tag (kept then at a measured 5–14%) had no other
job. What remains bitwise, tested, and structural: **thread-count
determinism and repeat-run determinism at a fixed configuration**. The
B-independence tests are demoted to `assert_terms_close`; the 32-entry
fingerprint net survives as the *unintended*-perturbation detector
(empirically it never even moved — see S1/S2 below).

## Track R — grow-only, parallel rebucket (`6a18fa1`, `5ed788d`)

- R1: `rebucket` clamps to `max(desired_bits, current bits)` — never
  coarsens. `B` is now a function of the term-count *history* (running max),
  still deterministic per circuit+input.
- R2: `Gf2Hash::row_parity` makes refine O(n) (it paid O(n·bits) via full
  `bucket_of` per term); refine/coarsen parallelize per bucket pair above
  the 8192-term worth-splitting threshold.
- Ising CSVs byte-identical; fingerprint net untouched (fixed hashes, no
  `propagate`).

Probe (n=10⁶, W=2, through `propagate`), ms/layer v0.4 → post-R:

| cell | 1t | 8t | 16t | 32t |
|---|---|---|---|---|
| gu2q | 348.6 → 207.5 | 186.1 → 28.6 | 204.0 → 22.0 | 210.3 → 15.2 (**13.8×**) |
| trotter | 116.7 → 107.9 | 32.9 → 16.0 | 32.4 → 12.2 | 34.9 → 10.4 (**3.35×**) |

gu2q's serial-rebucket share fell 74% → 0.0%; trotter's 46% → ~8–9%
(residual = genuine growth refines, now parallel). Trotter's retrograde
scaling past 8t is gone. `rebucket_1e6/refine_coarsen` criterion reference
(no committed prior): 7.46 ms at 10⁶ (32t pool).

## Track S — de-tag + split-stream sort + fused merge

### S1 (`a7cc8e9d`) and the regression it shipped (`6f3493e`)

S1 removed the tag column, added worker-persistent `SortScratch` (u32 perm +
tmp columns, one gather pass instead of two, zero steady-state allocations)
— and switched the per-run sort to `sort_unstable_by`. The campaign caught
that switch as a large regression: rotation_zz/1e6 **+77%**, cnot +43%,
gu2q +11%, sort busy-share 40% → 71–81%. Cause: a gather run is a
concatenation of per-delta streams each drawn from one sorted bucket, and
the stable driftsort's natural-run detection had been silently doing most of
the sort's work; pdqsort has no run merging. One-line fix back to the stable
`sort_by` (stability is irrelevant — adaptivity is the point), recorded in
the fn doc so it doesn't get "simplified" again. **Lesson recorded: the old
sort was never a plain O(n log n) comparison sort on this data.**

Post-fix S1 vs v0.4 (criterion, fixed B): gu2q −20%, rotation_w4 −14%,
rotation_zz/10⁴ −8%, everything else within noise. Fingerprints: **0 of 32
entries changed** — the fixtures only ever merge ≤2 contributions per key,
where IEEE754 addition commutes exactly; same for the Ising CSVs
(byte-identical: the quench is all rotations).

### S2 (`16ba505`): id/rest split + `merge2_into`

Every built-in's delta set contains the identity delta (entry 0); its rows
keep their keys, land in the member's own run, and inherit the bucket's
sorted unique order. `GatherRun` now carries them in separate `id` columns;
only the rest stream is sorted; a fused two-pointer `merge2_into` merges
id + rest straight into the destination with an id-first tie rule.
Exact-zero cos-rows are kept (signed zero). `rows_sorted` counter added
(probe JSON/TSV; perf-viz DRAM model updated to
`terms_in×T + 2×rows_gathered×T + 2×rows_sorted×T + terms_out×T`).

Criterion S1b → S2: rotation_zz/1e6 **−29%**, rotation_w4 −20%, gu2q −19%,
cnot −10%, clifford1q −8%. Sorted fraction (`rows_sorted/rows_gathered`):
rotation_zz 0.40, trotter 0.14, gu2q 0.73, cnot 0.75. Rotation's sort share
collapsed 33% → 8% of busy; merge (which absorbed the interleave) is now the
largest busy phase (39–45%) for rotation/trotter. Fingerprints and CSVs
again unchanged.

## Track N — placement

- **N0 diagnostics** (perf-stat, post-R): gu2q IPC 2.32 → 1.21 and
  cycles/string 1636 → 3205 going 8t → 32t (hyperthread sharing + memory);
  trotter at 32t drives **36.3 GB/s attributable DRAM traffic** (15.3 read +
  21.3 write) against the measured ~45–49 GB/s box ceiling — genuinely near
  the wall — with traffic *balanced across sockets* (S0 ≈ S1), i.e. pages are
  spread independent of which socket touches them.
- **N1 experiment — negative result, reverted.** Static contiguous
  coset→worker assignment via `rayon::broadcast` (stable worker index, one
  Mutex'd mega-slice per worker; `PAULISTRINGS_STATIC_COSETS=1`) measured
  **1.25–1.9× slower** than work-stealing in 7 of 8 cells (probe, 16/32t:
  rotation 1.90×/0.93×, gu2q 1.59×/1.64×, trotter 1.41×/1.25×, cnot
  1.53×/1.06×). Stragglers with no stealing cost far more than page locality
  recovers. The code is not in the tree (worktree change discarded); the
  A/B JSONs are in the session scratchpad only. A future variant would need
  stealing *within* a socket + stable socket-level partition (or block-cyclic
  assignment), plus NUMA-aware first touch of the bucket columns — recorded
  as future work, not attempted.

## Open after v0.5

- Merge is now the dominant busy phase for rotation/trotter at high thread
  counts (39–45%) and still grows with t — the coherence/USL-κ item stands;
  trotter at 32t is near the DRAM ceiling, so the next wins there are
  traffic reduction (e.g. in-place cos-scaling of the id stream rather than
  copying it through the run) or real NUMA partitioning.
- cnot idle ~15–20% at 32t (load imbalance on fanout-1 channels);
  `MIN_COSETS_FOR_PARALLEL`/`GATHER_OUTPUT_MAJOR_MIN_R` remain unswept.
- The §8.3 small-sum fast path remains unimplemented.
- Shared-box caveats apply throughout (loadavg 1–7 during these campaigns);
  criterion deltas above are well past the ±5% noise floor except where
  marked as noise.
