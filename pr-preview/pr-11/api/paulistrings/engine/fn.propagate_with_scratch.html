Expand description

propagate with a caller-held LayerScratch.

Behaves identically to propagate — it is the implementation — but lets the caller retain the scratch’s high-water buffer capacity across calls (a Trotter driver stepping an observable), and, under the phase-timing feature, read the per-phase counters afterwards through LayerScratch::take_stats (the method — and so a resolvable doc link to it — exists only when that feature is enabled).

It is also the only entry point that records a TermTrace — the always-compiled, opt-in per-layer term counts. Call LayerScratch::enable_term_trace before propagating and LayerScratch::take_term_trace afterwards; propagate, which owns its scratch, never enables it.

§Progress logging

This is where the events described under propagate are emitted: target paulistrings::propagate, INFO on entry and exit, DEBUG per layer. Every event is emitted on the calling thread, outside the engine’s Rayon region, so a logger implementation never runs inside a parallel layer.
