Default for PropagateOptions::small_sum_threshold.

The direct path saves the bucketed layer’s fixed per-layer cost but pays a per-term cost that rises as its hash map leaves cache, where the sorting engine’s is flat in the term count; the crossover is workload-dependent. 2048 is the largest value, in a measured sweep across representative workloads, at which no configuration regresses; see research/FINDINGS.md for the sweep. It also sits below desired_bits’s worth_splitting floor (DEFAULT_MIN_BUCKETS × MIN_TERMS_PER_TASK = 8192), so a sum on this path is one the sorting engine would have run in few buckets anyway.
