1//! [`PartitionedTruncation`] — truncation whose layer pass is collective.
2//!
3//! In partitioned mode each partition holds a *disjoint subset* of the terms
4//! (ARCHITECTURE.md §Partitioning), so a [`TruncationPolicy`] splits cleanly
5//! in two:
6//!
7//! - [`keep_term`](TruncationPolicy::keep_term) is per term and needs nothing: it runs inside the merge, on the complete summed coefficient of a key, and a key lives on exactly one partition.
8//! - [`finalize_layer`](TruncationPolicy::finalize_layer) may be *global*, and a partition cannot see the global layer.
9//!   [`ApproxTopN`] chooses an octave edge from the histogram of the whole layer — exactly the sum of the per-partition histograms — so one `allreduce` makes every partition choose the same edge, and the union of the retained sets is bit for bit the single-partition answer.
10//!
11//! Exact [`TopN`](crate::truncation::TopN) has no such reduction: the `n`-th
12//! largest magnitude is a distributed *k*-th selection, not a sum. It is
13//! rejected at compile time rather than approximated — see the trait docs.
14

23/// A truncation policy usable in partitioned propagation: its layer finalization is collective.
24///
25/// # The contract
26///
27/// A truncation policy that finalizes a layer (`finalizes_layer() == true`) must implement [`PartitionedTruncation`]; the trait's default panics otherwise, since finalizing a layer with no collective form would let partitions diverge silently.
28/// [`finalize_layer_partitioned`](Self::finalize_layer_partitioned) is called on every layer, on every partition, in lock-step: a collective is only well-defined if every partition issues the same calls in the same order, so an implementation must not skip a call on a partition that happens to have nothing to do, and must derive its decision only from all-reduced values so every partition applies the identical predicate to its own terms.
29/// Under those two rules the retained set is exactly what a single partition holding the whole sum would have retained.
30///
31/// # Which policies implement it
32///
33/// [`CoefficientThreshold`] and [`WeightCutoff`] are per-term filters with no layer pass, so they take the default no-op body.
34/// [`ApproxTopN`] all-reduces its octave histogram every layer, regardless of what the partition rows do.
35/// [`And`] runs both sides in order, like [`And::finalize_layer`](TruncationPolicy::finalize_layer); [`Or`] runs neither, because its unpartitioned `finalize_layer` is the trait's no-op default rather than either child's, and the two must agree.
36///
37/// ```
38/// use paulistrings::truncation::{And, ApproxTopN, CoefficientThreshold};
39/// use paulistrings::PartitionedTruncation;
40///
41/// fn propagate_partitioned<T: PartitionedTruncation<1>>(_policy: T) {}
42///
43/// propagate_partitioned(And(CoefficientThreshold(1e-12), ApproxTopN(1_000)));
44/// ```
45///
46/// # Why [`TopN`](crate::truncation::TopN) is rejected
47///
48/// ```compile_fail
49/// use paulistrings::truncation::TopN;
50/// use paulistrings::PartitionedTruncation;
51///
52/// fn propagate_partitioned<T: PartitionedTruncation<1>>(_policy: T) {}
53///
54/// // error[E0277]: the trait bound `TopN: PartitionedTruncation<1>` is not
55/// // satisfied — exact top-n has no collective form yet.
56/// propagate_partitioned(TopN(10));
57/// ```
58///
59/// `TopN` needs the exact `n`-th largest `|c|²` of the whole layer — a distributed *k*-th selection, not a reduction — so it is rejected at compile time rather than approximated, which would silently change what `TopN` means.
60/// Use [`ApproxTopN`] when `n` is a memory budget.
61pub trait PartitionedTruncation<const W: usize>: TruncationPolicy<W> {
62    /// The collective layer pass: `local` is this partition's slice of the layer, `coll` its view of the group.
63    ///
64    /// Called on every layer on every partition, in lock-step, for a policy whose [`finalizes_layer`](TruncationPolicy::finalizes_layer) is `true` — the driver skips the call entirely on one that answers `false` (see the trait docs).
65    /// The default is no layer pass at all, which is correct exactly for the policies that have none, so it asserts that this is one of them rather than silently dropping a `finalize_layer` a caller was relying on.
66    ///
67    /// # Panics
68    ///
69    /// If the policy reports [`finalizes_layer()`](TruncationPolicy::finalizes_layer) and has not overridden this method.
70    fn finalize_layer_partitioned(&self, _local: &mut PauliSum<W>, _coll: &dyn Collectives) {
71        assert!(
72            !self.finalizes_layer(),
73            "{} has a layer finalization but no partitioned one. A layer pass \
74             in partitioned mode has to be collective — every partition sees \
75             only a disjoint slice of the layer — so the default no-op body \
76             cannot stand in for it. Override `finalize_layer_partitioned` \
77             (see `ApproxTopN`, which all-reduces its octave histogram), or \
78             use `ApproxTopN` itself.",
79            std::any::type_name_of_val(self),
80        );
81    }
82}

84/// Per-term only — the default no-op layer pass is the whole story.
85impl<const W: usize> PartitionedTruncation<W> for CoefficientThreshold {}

87/// Per-term only — the default no-op layer pass is the whole story.
88impl<const W: usize> PartitionedTruncation<W> for WeightCutoff {}

90impl<const W: usize, A, B> PartitionedTruncation<W> for And<A, B>
91where
92    A: PartitionedTruncation<W>,
93    B: PartitionedTruncation<W>,
94{
95    /// Both sides, first then second — the order [`And::finalize_layer`](TruncationPolicy::finalize_layer) uses, and the same order on every partition, so the collectives stay in lock-step.
96    fn finalize_layer_partitioned(&self, local: &mut PauliSum<W>, coll: &dyn Collectives) {
97        self.0.finalize_layer_partitioned(local, coll);
98        self.1.finalize_layer_partitioned(local, coll);
99    }
100}

102impl<const W: usize, A, B> PartitionedTruncation<W> for Or<A, B>
103where
104    A: PartitionedTruncation<W>,
105    B: PartitionedTruncation<W>,
106{
107    /// Neither side — `Or`'s unpartitioned [`finalize_layer`](TruncationPolicy::finalize_layer) is the trait's no-op default rather than either child's, and the two paths have to agree.
108    ///
109    /// The children are still bounded by this trait: a composition is partitioned-safe only if its parts are, which keeps the bound meaningful if `Or` ever grows a layer pass.
110    fn finalize_layer_partitioned(&self, _local: &mut PauliSum<W>, _coll: &dyn Collectives) {}
111}

113impl<const W: usize> PartitionedTruncation<W> for ApproxTopN {
114    /// One `allreduce_sum_u64` of `[len, hist…]`, then the single-partition edge walk and retain.
115    ///
116    /// Octave populations are additive across a disjoint partition of the terms, and so is the term count, so the reduced buffer is exactly the histogram and length the single-partition path would have computed.
117    /// `octave_edge` is a pure function of those two, so every partition reaches the same edge decision and retains its own terms against it, with no second round of communication.
118    ///
119    /// The length rides in slot 0 of the same buffer rather than in its own reduction.
120    /// Neither early exit of the single-partition path is taken here, because neither test can be answered before the reduction — a partition that returned early would desynchronize the group.
121    fn finalize_layer_partitioned(&self, local: &mut PauliSum<W>, coll: &dyn Collectives) {
122        let hist = octave_histogram(local);
123
124        // [len, bin 0, bin 1, …]. `u32` counters widen to `u64` for the reduction: `P` partitions of up to `u32::MAX` terms each can overflow a `u32` bin, and the transport's reduction is `u64`.
125        let mut packed = [0u64; 1 + APPROX_BINS];
126        packed[0] = local.len() as u64;
127        for (slot, &count) in packed[1..].iter_mut().zip(hist.iter()) {
128            *slot = u64::from(count);
129        }
130        coll.allreduce_sum_u64(&mut packed);
131
132        let total = packed[0] as usize;
133        let edge = octave_edge(&packed[1..], total, self.0);
134        retain_at_or_above(local, edge);
135    }
136}

149    /// Split `sum` into `1 << pbits` partitions, run the policy's collective layer pass on each in its own thread, and gather the result.
150    ///
151    /// One `std::thread::scope` per call with one thread per partition, which is what the in-process transport's blocking collectives need: every rank has to be able to make progress independently.
152    fn partitioned_finalize<const W: usize, T>(
153        policy: &T,
154        sum: &PauliSum<W>,
155        pbits: u8,
156    ) -> PauliSum<W>
157    where
158        T: PartitionedTruncation<W>,
159    {
160        let rows = PartitionRows::<W>::from_seed(sum.num_qubits(), pbits, PSEED);
161        let p = rows.num_partitions() as u32;
162        let parts: Vec<PauliSum<W>> = (0..p).map(|r| sum.filter_partition(&rows, r)).collect();
163        assert_eq!(
164            parts.iter().map(PauliSum::len).sum::<usize>(),
165            sum.len(),
166            "the split must be a partition of the terms",
167        );
168
169        let group = InProcessTransport::group(p);
170        let gathered: Vec<PauliSum<W>> = std::thread::scope(|scope| {
171            let handles: Vec<_> = parts
172                .into_iter()
173                .zip(group)
174                .map(|(mut local, transport)| {
175                    scope.spawn(move || {
176                        policy.finalize_layer_partitioned(&mut local, &transport);
177                        (transport.rank(), local)
178                    })
179                })
180                .collect();
181            let mut slots: Vec<Option<PauliSum<W>>> = (0..p).map(|_| None).collect();
182            for handle in handles {
183                let (rank, local) = handle.join().expect("partition thread panicked");
184                slots[rank as usize] = Some(local);
185            }
186            slots.into_iter().map(Option::unwrap).collect()
187        });
188
189        for local in &gathered {
190            local.assert_invariants();
191        }
192        let merged = PauliSum::<W>::merge_partitions(gathered);
193        merged.assert_invariants();
194        merged
195    }

197    /// The whole point: partitioned finalization is *exactly* the single-partition one, for every `P`.
198    fn assert_matches_single_partition<const W: usize, T>(
199        policy: &T,
200        input: &PauliSum<W>,
201        pbits: u8,
202        what: &str,
203    ) where
204        T: PartitionedTruncation<W>,
205    {
206        let mut want = input.clone();
207        policy.finalize_layer(&mut want);
208
209        let got = partitioned_finalize(policy, input, pbits);
210        assert_eq!(
211            got.len(),
212            want.len(),
213            "{what}: partitioned kept {} terms, single-partition {}",
214            got.len(),
215            want.len(),
216        );
217        assert_same_terms(&got, &want, what);
218    }

253    /// A sum confined to one octave of `|c|²` is wiped to empty — the degenerate case documented on `ApproxTopN` — and it has to be wiped on *every* partition, from the global histogram, not decided locally.
254    /// Magnitudes 1, 1⅛, 1¼, 1⅜ square into `[1, 2)`.
255    #[test]
256    fn approx_top_n_partitioned_wipes_a_single_octave_sum() {
257        let mags = [1.0f64, 1.125, 1.25, 1.375];
258        let input = PauliSum::<1>::from_sorted_columns(
259            (0u64..mags.len() as u64).map(|i| [i]).collect(),
260            vec![[0u64]; mags.len()],
261            mags.iter().map(|&m| Complex64::new(m, 0.0)).collect(),

264        for pbits in [1u8, 2] {

271                pbits,
272                &format!("single octave P=2^{pbits} n=4"),
