Expand description

What a coset task waits on before it reads a received row.

The partitioned layer hands one of these to its RecvRows, which calls wait_chunk at the top of append_into with the chunk its output bucket belongs to. A blocking transport’s implementation is empty: everything arrived before the body ever ran.

Sync because the coset loop calls it from every Rayon worker at once. An implementation that talks to MPI must therefore serialize itself — one thread in the library at a time is exactly MPI_THREAD_SERIALIZED.

fn wait_chunk(&self, k: usize)

Block until every row of chunk k has arrived.

Must be safe to call concurrently, repeatedly, and out of order — a coset task knows only its own chunk, and Rayon decides who runs when.
