1//! Classical simulation of quantum circuits by Pauli propagation: the library evolves operators in the Pauli basis under gates and noise channels, forward or Heisenberg, at the term counts (10⁶–10⁸) where state-vector or tensor-network simulators are infeasible. Not a state-vector, tensor-network, stabilizer, or MPS simulator — see ARCHITECTURE.md.
2//!
3//! # Quick example
4//!
5//! Heisenberg-evolve the observable `Z₀ + 0.5·X₁` through an `H` gate on qubit 0:
6//!
7//! ```
8//! use paulistrings::{
9//!     BuildAccumulator, Circuit, Direction, PauliString, Phase, TruncationPolicy,
10//!     channel::Clifford1Q, propagate,
11//! };
12//! use num_complex::Complex64;
13//!
14//! let mut acc = BuildAccumulator::<1>::new(2);
15//! acc.add_term(PauliString::<1>::z(0), Phase::ONE, Complex64::new(1.0, 0.0));
16//! acc.add_term(PauliString::<1>::x(1), Phase::ONE, Complex64::new(0.5, 0.0));
17//! let observable = acc.finalize();
18//!
19//! let mut circuit = Circuit::<1>::new(2);
20//! circuit.push(Clifford1Q::h(0));
21//!
22//! struct KeepAll;
23//! impl<const W: usize> TruncationPolicy<W> for KeepAll {}
24//!
25//! let evolved = propagate(&circuit, observable, &KeepAll, Direction::Heisenberg);
26//!
27//! // H conjugates Z → X, so the Z₀ term becomes X₀; the X₁ term is untouched.
28//! assert_eq!(evolved.len(), 2);
29//! ```
30//!
31//! # Module map
32//!
33//! - [`PauliString`], [`PauliSum`], [`BuildAccumulator`], [`Phase`] — the data model (ARCHITECTURE.md §Data-Model).
34//! - [`Circuit`], [`Channel`] (built-ins in [`channel`]) — gates and noise.
35//! - [`TruncationPolicy`] (built-ins in [`truncation`]) — composable per-term and per-layer filters.
36//! - [`propagate`] / [`Direction`] / [`propagate_with_options`] — the propagation entry point (ARCHITECTURE.md §Engine).
37//! - [`ProductBasis`] / [`StabilizerState`] — read-out-only contraction states, never evolved.
38//! - [`engine`] / [`engine::partitioned`] — the bucketed engine and its NUMA/distributed partitioning (ARCHITECTURE.md §Engine, §Partitioning); [`propagate`] is the front door for almost all callers.
39//! - [`examples`] — worked-example walkthroughs of full-scale simulations.
40//!
41//! # Choosing `W`
42//!
43//! [`PauliString`] is generic over a const `W: usize`, the number of 64-bit words per `x`/`z` part; `PauliString<W>` covers up to `64·W` qubits (ARCHITECTURE.md §Width). Pick the smallest `W` that fits; the Python bindings monomorphize at `W ∈ {1, 2, 4, 8, 16}` and dispatch on `num_qubits` at the boundary.
