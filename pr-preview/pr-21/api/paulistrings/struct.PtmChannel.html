Struct PtmChannel 

Source 
pub struct PtmChannel { /* private fields */ }
Expand description

A one- or two-qubit gate or noise channel, stored as its Pauli-transfer matrix.

Built by the named constructors: the Cliffords hadamard, phase_gate, pauli_x, pauli_y, pauli_z, cnot, cz, swap; the general unitaries unitary_1q, unitary_2q; and the noise channels depolarizing, dephasing, pauli_channel, depolarizing_2q, amplitude_damping.

On the support, Paulis are indexed x | (z << 1) per qubit (I = 0, X = 1, Z = 2, Y = 3), the constructor’s first qubit in the low two bits. Channel::apply maps input Pauli s to Σ_t ptm[s][t] · P_t, and Channel::apply_adjoint reads the transpose.

pub fn pauli_channel(qubit: usize, px: f64, py: f64, pz: f64) -> Self

Single-qubit Pauli channel E(ρ) = (1-px-py-pz)ρ + px·XρX + py·YρY + pz·ZρZ.

It scales X by 1 - 2(py + pz), Y by 1 - 2(px + pz) and Z by 1 - 2(px + py), so (p/3, p/3, p/3) is depolarizing and (0, 0, p) is dephasing.

§Panics

Unless each probability lies in [0, 1] and px + py + pz ≤ 1.

Source

pub fn depolarizing_2q(q0: usize, q1: usize, p: f64) -> Self

Two-qubit depolarizing noise E(ρ) = (1-p)ρ + (p/15)·Σ_k P_k ρ P_k over the 15 non-identity two-qubit Paulis.

Every Pauli that is non-identity on the pair is scaled by 1 - 16p/15.

§Panics

If q0 == q1, or unless p ∈ [0, 1].

Source

pub fn amplitude_damping(qubit: usize, gamma: f64) -> Self

Single-qubit amplitude damping with Kraus operators K_0 = |0⟩⟨0| + √(1-γ)|1⟩⟨1|, K_1 = √γ |0⟩⟨1|.

Not self-adjoint: apply is the Schrödinger map (I → I + γZ, Z → (1-γ)Z) and apply_adjoint its Heisenberg dual (I → I, Z → (1-γ)Z + γI); both scale X and Y by √(1-γ).

§Panics

Unless gamma ∈ [0, 1].
